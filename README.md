# MINT-CAD

MINT-CAD ist eine für den Schulunterricht vereinfachte Fassung von [FreeCAD](https://www.freecad.org) (Basis: FreeCAD 1.1.4):
Skizzieren, Konstruieren (Part Design), Technische Zeichnungen (TechDraw), einfache Baugruppen und FEM, mit deutscher Oberfläche
und einem aufgeräumten Menüband. `.FCStd`-Dateien bleiben mit FreeCAD austauschbar.

**Download:** siehe [Releases](../../releases) (macOS Apple Silicon, später Windows und Linux).
